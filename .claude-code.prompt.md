# Start

This repo will contain an emacs extension. We will start by initializing the project and a CLAUDE.md

The vision here is that while I'm working, I can have a dedicated buffer open and showing a "heads up display" for the current code. This will feature several analyses of the current code context

For the file open in the current code window:

- what is its current git status.
- what other files historically change at the same time this file changes (similar to adam tornhill's code-maat and code-as a crime scene)
- Who are the people who have touched this file, accompanied by the number of times they've touched it, sorted
- An llm summary in <3 sentences of the purpose of this file (generated by claude, cached hourly)
- An llm summary in <5 sentences of the history of this file (generated by claude, cached daily)

To start with lets generate a! CLAUDE.md

For code style, prefer a simple functional style and keep the following values in mind

- Using the cl-loop loop facility is a great idea
- Using dash.el and threading operators is a great idea
- namespace functions and variables with with `gim-code-hud/...`
- lexical bindings all the way

You can enter a "prototype with emacs" mode where you try things out using the emacsclient skill.
Before running anything that can be destructive to emacs or the file system you MUST ask for permission and verification.
